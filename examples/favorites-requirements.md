# 收藏功能需求约定（演示）

此文件是假设用户已明确选择以下行为的演示，不代表真实项目需求。

## 目标与范围

登录用户可以添加、取消和查看自己的收藏，收藏跟随账号跨设备同步。本期不包含分类、分享和搜索。

## 示例中已决定的规则

- 收藏仅对本人可见。
- 首次点击收藏即添加，再次点击即取消；同一账号对同一内容只保留一条收藏。
- 原内容删除后，保留收藏时的标题并显示失效状态，无法打开原内容；用户仍可取消收藏。
- 未登录时点击收藏，提示先登录，不写入收藏。
- 保存失败时提示失败，界面恢复操作前状态，允许重试。

## 建议默认

- 收藏列表按收藏时间倒序排列。
- 无收藏时显示空状态和返回浏览入口。

以上是可调整的实现默认，不应标为用户逐项确认的要求。

## 验收场景

| 条件 | 操作 | 预期结果 |
|---|---|---|
| 已登录且尚未收藏 | 点击收藏 | 显示已收藏，列表出现该内容 |
| 已收藏 | 再次点击收藏 | 取消收藏，列表移除该项 |
| 同一账号在另一设备登录 | 打开收藏列表 | 可以看到该账号保存的收藏 |
| 另一个账号已收藏内容 | 查看自己的收藏 | 不出现另一个账号的收藏记录 |
| 原内容已删除 | 打开收藏列表 | 显示已保存标题及失效状态，原内容无法打开 |
| 保存请求失败 | 点击收藏 | 提示失败并恢复原状态，不显示虚假的成功状态 |
| 未登录 | 点击收藏 | 提示登录，不保存收藏 |
